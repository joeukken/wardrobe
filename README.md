\# Smart Wardrobe \& AI Outfit Planner



An AI-powered digital wardrobe that recommends outfits from the user's

actual clothing collection based on occasion and weather.



\## Features



\- Digital wardrobe management

\- Add, edit and delete clothing items

\- AI-powered outfit recommendations

\- Occasion-aware recommendations

\- Weather-aware recommendations

\- Save favorite outfits

\- Plan outfits on a calendar

\- Outfit history

\- FastAPI backend

\- Gemini Vision multimodal reasoning
